# Sample-level cohort analysis

Tutorials for **sample-level / multi-sample cohort** analysis of single-cell data:
quantifying how donors or samples differ from one another, and how that variation
relates to a sample-level covariate (disease status, treatment, genotype...) — distinct
from batch correction, which treats sample-to-sample variation as a nuisance to remove
rather than a signal to characterise.
